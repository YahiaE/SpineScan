1. Welcome & Account Connection

Purpose: Link the user’s Discogs account.

User Flow

User opens the app.

Welcome screen briefly explains the app’s purpose:

“Scan your CD spines and add them directly to your Discogs collection.”

User taps Connect Discogs Account.

User logs into their Discogs account and authorizes the app.

After authorization, the user is returned to the app.

The app confirms the account is connected.

End Result

User arrives at the main scanning screen.

2. Start a Scan

Purpose: Capture CD spine images.

User Flow

The main screen shows a button:

Scan CDs

User taps the button.

The camera opens with simple instructions:

“Line up your CD spines and take a photo.”

User takes a photo of one or multiple CD spines.

User reviews the photo.

Options:

Retake photo

Use photo

End Result

The image is submitted for processing.

3. Image Processing

Purpose: Convert the photo into readable album titles.

User Flow

After confirming the photo, the user sees a processing screen.

The app shows a progress indicator:

“Analyzing CD spines…”

The app detects text from the image.

The extracted album titles are matched to album entries.

End Result

The user is shown a generated album list.

4. Review Detected Albums

Purpose: Let the user verify and correct the detected albums.

User Flow

The user sees a scrollable list of detected albums.

Example:

Radiohead — OK Computer

Miles Davis — Kind of Blue

Daft Punk — Discovery

Each item in the list can be tapped.

User options:

Tap an album to edit it

Remove an album

Add a missing album manually

If the user taps an album:

A search/edit screen opens.

User can:

Correct the text

Search for the correct album

User selects the correct album entry.

The list updates.

End Result

The user has a clean, verified album list.

5. Confirm Import

Purpose: Prepare albums for Discogs.

User Flow

The user taps Import to Discogs.

A confirmation screen appears showing:

Number of albums being imported

Album list preview

Example:

“Import 14 albums to your Discogs collection?”

Options:

Confirm

Go back and edit

End Result

Import process begins.

6. Import Progress

Purpose: Show the user that albums are being added.

User Flow

A progress screen appears showing:

Albums being added one by one

A progress bar

Example:

Adding to collection…

✓ Radiohead — OK Computer
✓ Miles Davis — Kind of Blue
✓ Daft Punk — Discovery

End Result

Import completes successfully.

7. Completion Screen

Purpose: Confirm success.

User Flow

A success message appears:

“Albums added to your Discogs collection.”

Options:

Scan more CDs

View your Discogs collection

8. Optional Features (Secondary Flows)

These improve usability but are not required.

Scan History

Users can view previous scans.

Each entry shows:

Date of scan

Albums imported

Photo taken

Rescan / Fix Errors

If OCR fails:

The app shows:

“No albums detected.”

Options:

Retake photo

Try another scan

Simplified User Journey

Entire flow in one sequence

Open app

Connect Discogs account

Tap Scan CDs

Take photo of CD spines

App detects album titles

User reviews and edits album list

Tap Import to Discogs

Albums are added to collection

Success confirmation
